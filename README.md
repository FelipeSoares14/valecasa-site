# Vale Casa

Site e materiais digitais da campanha Vale Casa.

| Pasta / arquivo | O que é |
|---|---|
| `index.html`, `assets/`, `img/` | O site |
| `design-system/` | Design system da marca |
| `auditoria/` | Auditoria do site |
| `analise-figma/` | Análise do arquivo do Figma |
| `icones-comodidades/` | Os 150 ícones de comodidades (SVG), o catálogo e os scripts que geram o pacote |
| `ilustracoes/` | Ilustrações de estados vazios (404, busca vazia, sem foto) |

Os arquivos de design (Figma, PSD, AI, fotos, 3D, fontes e documentos da marca) ficam no Drive, na pasta `valecasa campanha`.

## Como abrir

Abra o `index.html` no navegador.
